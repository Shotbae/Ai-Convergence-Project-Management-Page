## 1. 💡 기획 배경 및 목적
* 수강 신청 이후 발생하는 복잡한 명단 정리 작업(출석부 생성, 정원 및 대기자 분리, 중복 신청자 확인 등)을 수작업으로 진행하던 실무자의 업무 부담을 획기적으로 줄이기 위해 제작되었습니다.
* 직관적인 팝업(UI) 메뉴를 통해 스크립트나 함수를 모르는 사용자도 버튼 클릭 한 번으로 복잡한 엑셀 데이터 가공과 PDF 생성 작업을 처리할 수 있습니다.

## 2. ✨ 주요 기능 (Features)
사용자 친화적인 팝업창에서 기수와 강좌를 선택한 후, 아래의 6가지 핵심 기능을 원클릭으로 실행할 수 있습니다.

* **📄 강좌별 출석부 생성:** 선택한 단일 강좌의 출석부를 `출석부템플릿`을 바탕으로 자동 생성합니다. 정원(기본 12명)을 기준으로 등록자와 대기자를 분리하며, 교사 직인 자동 삽입 기능을 지원합니다.
* **📑 전체 출석부 일괄 생성:** 선택한 기수에 포함된 모든 강좌의 출석부를 한 번에 일괄 생성합니다. (이미 생성된 강좌는 중복을 방지하기 위해 자동으로 건너뜁니다.)
* **👥 중복 신청자 명단 생성:** 일자 또는 강좌를 중복으로 신청한 학생을 색출하여 사유(일자중복, 강좌중복 등)와 함께 별도의 시트로 추출합니다.
* **⏳ 대기자 명단 생성:** 강좌별 정원을 초과하여 대기 번호를 받은 학생들의 명단과 대기 강좌 목록을 따로 모아 시트를 생성합니다.
* **🏫 담임 배포 명단 생성:** 학급 담임교사가 학생별 수강 상태를 한눈에 파악할 수 있도록 종합 명단을 생성합니다. 직관적인 색상 코딩(🔴 빨강: 중복, 🟡 노랑: 대기)이 자동 적용되어 가독성이 뛰어납니다.
* **🖨️ 통합 출석부 PDF 출력:** 생성된 해당 기수의 모든 출석부 시트들을 임시 시트로 모아 하나의 통합 PDF 파일로 변환한 뒤, 구글 드라이브 최상단에 자동 저장합니다.

## 3. 📋 필수 사전 준비 (Sheet 구조)
이 스크립트가 정상적으로 작동하려면 구글 스프레드시트 내에 아래 시트들이 준비되어 있어야 합니다.
* `{기수}신청현황원본` (예: 1기신청현황원본): 학생별 수강 신청 데이터 원본 시트
* `출석부생성`: 작업 기수 및 강좌 정보가 임시 저장되는 메인 시트 (B3: 기수, B4: 강좌명)
* `출석부템플릿`: 출석부 생성 시 디자인 기준이 되는 템플릿 시트
* `강좌기본정보`: 강좌 코드, 요약명, 정원 등의 기준 데이터 시트
* `교사직인`: 교사 이름과 직인 이미지가 매핑된 시트

## 4. 🚀 사용 방법 (How to Use)
1. **메뉴 실행:** 구글 스프레드시트 상단 메뉴에서 `[⚙️ 출석부 관리] > [🚀 작업 설정 열기]`를 클릭합니다.
2. **기수 및 강좌 선택:** 나타나는 팝업창에서 작업할 **기수**(필수)를 선택하고, 특정 강좌만 작업할 경우 **강좌**를 선택합니다.
3. **작업 버튼 클릭:** 원하는 작업의 버튼(예: 📑 전체 출석부 일괄 생성)을 클릭합니다.
4. **결과 확인:** 하단에 '작업을 실행 중입니다...' 메시지가 표시된 후, 작업이 완료되면 완료 안내 팝업과 함께 새 시트나 PDF 파일이 생성된 것을 확인할 수 있습니다.
